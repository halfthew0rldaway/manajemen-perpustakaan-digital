# 🚀 Quick Start Guide

## Instalasi Cepat

```bash
# Clone atau extract project
cd perpustakaan-digital

# Jalankan script setup otomatis
chmod +x setup.sh
./setup.sh

# Start server
php artisan serve
```

Akses aplikasi di: `http://localhost:8000`
